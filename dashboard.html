GitHub — لرفع الصور

محتاج Token من GitHub عشان الداشبورد ترفع الصور مباشرة على الريبو:

  1. افتح github.com → Settings → Developer settings
  2. Personal access tokens → Tokens (classic) → Generate new token
  3. علّم على repo → Generate → انسخ التوكين
